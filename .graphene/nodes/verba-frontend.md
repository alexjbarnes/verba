- Article extraction (extractArticle/bodyWithImages in main.js), fixed 2026-09-24/25 on a platformengineering.org (Webflow) post: (1) the pre-Readability landmark strip (header/footer/nav/aside) used to delete a Webflow <header class="section_sidebar-right"> that wrapped the ENTIRE article, so Readability fell back to related-post cards. Now a landmark is only removed if it holds <= half the page's <p> text. (2) Tables: each <tr> becomes one line with cells joined by " | " (cells trimmed, whitespace text directly in TABLE/THEAD/TBODY/TFOOT/TR skipped); layout tables with one cell per row just read as content. Don't collapse whitespace inside cells: layout-table essays (e.g. paulgraham.com) live in a single cell. (3) Lines holding only zero-width chars (Webflow empty paragraphs) are blanked; ZWJ is NOT stripped globally since emoji sequences use it. Already-saved articles keep their old body; there is no re-fetch, the user must re-add. Harness tip: the browser caches /main.js across navigations, so cache-bust the module src (main.js?v=timestamp) after edits or you test stale code. <!-- id:3840 src:article rendered related posts instead of body -->
- Link markers (bodyWithImages), 2026-09-25, seangoedecke.com post: Readability absolutises hash links against our injected <base>, so "#frag" arrives as a full same-page URL and used to pass the http(s) check; icon-only heading permalinks (<a class="heading-anchor"><svg/></a>) then printed their whole URL beside every heading. Now any link whose normArticleUrl equals the page's is unwrapped (text kept) or removed (no text). Also, LINK_MARKER/IMG_MARKER end at the first ")", so markerUrl() percent-encodes parentheses in marker URLs (Wikipedia "Skin_in_the_Game_(book)" was truncated with a stray ")"). - Whitespace in extraction (bodyWithImages walk), 2026-09-30, martinfowler.com post: many sites hard-wrap <p> text in their HTML source, and the reader (#reading-text is whitespace-pre-wrap) showed every source newline. The walk now collapses [ \t\n\r\f]+ to one space in text nodes (not \s, which would eat &nbsp;), drops a leading space when output already ends in space/newline, and passes text through untouched inside <pre> or an inline white-space:pre* style. Image marker text nodes are tracked in a Set and exempt, since they carry intentional \n\n. tests/share-import.test.js stubs DOM nodes (el2) for bodyWithImages; if the walk uses a new DOM method, add it to the stub (getAttribute was added).
