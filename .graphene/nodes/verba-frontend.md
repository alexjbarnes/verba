- Whitespace in extraction (bodyWithImages walk), 2026-09-30, martinfowler.com post: many sites hard-wrap <p> text in their HTML source, and the reader (#reading-text is whitespace-pre-wrap) showed every source newline. - Share intake (2026-10-22): sharedLink(raw) decides link vs text. It returns the first http(s) URL only when the text left after stripping every URL is at most SHARE_CAPTION_MAX (300) chars, i.e. a bare URL or URL plus headline as browsers and news apps send. Longer text is saved as-is with url null. Prompted by a shared newsletter ending in a markdown "## Sources" list: the first source fetched fine, so the whole share was swapped for that article. If a link fetch fails, importSharedText still saves the raw text (fetchSharedArticle returns null on any failure; url cleared, toast says saved as text). Callers: the Android share target and the Add-from-URL modal (bare URL, always a link). tests/share-import.test.js slices main.js from "async function fetchSharedArticle" to the sidebar marker; sharedLink and its const sit inside that slice, so keep anything added there self-contained. <!-- id:a07e src:bug: shared newsletter replaced by its first source link -->
- Quotes, section breaks, link spacing (2026-10-22, martinfowler.com fragments post): bodyWithImages emits a BLOCKQUOTE as `> ` on every line, with a bare `>` on the blank lines between its paragraphs so a multi-paragraph quote stays one block; nested quotes nest prefixes and the reader flattens them. renderReading turns each run of `>` lines into a <blockquote> that is inline-block w-full align-top, NOT block, so the \n\n around it stay ordinary paragraph gaps without the newline swallowing headings need. Its bar is color-mix(currentColor 35%) so the paper backgrounds' forced ink colour carries over. A line of only symbols (no \p{L}/\p{N}) renders as a centred section break with whitespace incl. &nbsp; collapsed: martinfowler's ❄ dividers are 16-&nbsp; runs that wrapped onto two lines at phone width. That part is render-side so it fixes already-saved bodies; quotes and link spacing need a re-add. Link markers move a space that sat just inside the <a> ("Parkinson’s </a>is") outside the brackets. stripImageMarkers strips `> ` for search and word counts. tidyBody() is the shared final cleanup.
